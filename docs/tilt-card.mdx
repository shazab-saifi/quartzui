# TiltCard

A modern React component that provides a tilt 3D effect on hover, animating as your mouse moves across the card. Great for interactive UIs, product cards, and dashboards.

## Installation

You can install the TiltCard component with the recommended CLI, or copy the implementation manually:

<InstallToggle
  cliCode="npx shadcn@latest add http://localhost:3000/r/tilt-card.json"
  manualCode={`'use client';
  
  import { motion, useMotionValue, useSpring, useTransform } from 'motion/react';
  import { useRef } from 'react';
  
  export const TiltCard = ({ children }: { children: React.ReactNode }) => {
    const ref = useRef<HTMLDivElement | null>(null);
    const x = useMotionValue(0);
    const y = useMotionValue(0);
    const mouseXSpring = useSpring(x);
    const mouseYSpring = useSpring(y);
  
    const rotateX = useTransform(
      mouseYSpring,
      [-0.5, 0.5],
      ['8.5deg', '-8.5deg']
    );
  
    const rotateY = useTransform(
      mouseXSpring,
      [-0.5, 0.5],
      ['-8.5deg', '8.5deg']
    );
  
    const handleMouseMove = (e: React.MouseEvent<HTMLDivElement, MouseEvent>) => {
      if (!ref.current) return;
      const rect = ref.current.getBoundingClientRect();
  
      const mouseX = e.clientX - rect.left;
      const mouseY = e.clientY - rect.top;
  
      const xPct = mouseX / rect.width - 0.5;
      const yPct = mouseY / rect.height - 0.5;
  
      x.set(xPct);
      y.set(yPct);
    };
  
    const handleMouseLeave = () => {
      x.set(0);
      y.set(0);
    };
  
    return (
      <motion.div
        ref={ref}
        onMouseMove={(e) => handleMouseMove(e)}
        onMouseLeave={handleMouseLeave}
        style={{ transformStyle: 'preserve-3d', rotateX, rotateY }}
        className="h-96 w-72 rounded-xl bg-gradient-to-br from-neutral-200/50 to-neutral-400/50 dark:from-neutral-900/60 dark:to-neutral-800/60"
      >
        <div
          style={{
            transform: 'translateZ(75px)',
            transformStyle: 'preserve-3d',
          }}
          className="absolute inset-3 overflow-hidden rounded-xl shadow-2xl"
        >
          {children}
        </div>
      </motion.div>
    );
  };
`} 
/>

## Features

- **3D tilt animation:** Card reacts in 3D to mouse movement.
- **Smooth motion:** Uses motion.dev for natural spring-physics animation.
- **Easy composition:** Accepts any React children.
- **Theming:** Card adapts to light/dark themes for seamless integration.

<hr style={{ borderColor: "var(--color-neutral-900)", borderWidth: 1 }} />

## Customization

- Adjust the inner card's markup and classes for your brand or content.
- Tweak spring/transform config for different tilt intensity.
- Modify the outer and inner div's styling for variant cards.

<hr style={{ borderColor: "var(--color-neutral-900)", borderWidth: 1 }} />

## Troubleshooting

- Ensure you have [motion.dev](https://motion.dev/) installed for animation support.
- If tilt isn’t responsive, verify parent/container styles aren’t interfering with pointer events.
- Card dimensions (`h-96 w-72`) and shadow may be customized for your layout.
