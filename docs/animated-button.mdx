## Usage

To use the animated button component, import it from `@/components/AnimatedButton`.

<CodeBlock code={`import AnimatedButton from '@/components/AnimatedButton';`} />

## Props

The animated button component takes the following props:

- `label`: The text to display on the button.
- `onClick`: The function to call when the button is clicked.
- `className`: Additional classes to apply to the button.
- `type`: The type of the button.
- `ariaLabel`: The aria-label for the button.
- `disabled`: Whether the button is disabled.
