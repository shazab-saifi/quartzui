# Animated Button

import { CodeBlock } from './CodeBlock';
import LiveCode from './LiveCode';
import InstallToggle from "./InstallToggle";

The `AnimatedButton` component is a modern, animated call-to-action button for your apps and websites. It features animated gradients, smooth interactions, and accessible props for maximum impact. Use it for landing pages, feature cards, or anywhere you want an eye-catching button.

## Installation

You can install the AnimatedButton component with the following CLI command, or copy the implementation manually:

<InstallToggle
  cliCode="npx shadcn@latest add http://localhost:3000/r/animated-button.json"
  manualCode={`
  'use client';
  
  import { cn } from '@/lib/utils';
  
  export type AnimatedButtonProps = {
    children: string;
    onClick: () => void;
    className?: string;
    type?: 'button' | 'submit' | 'reset';
    ariaLabel?: string;
    disabled?: boolean;
  };
  
  const AnimatedButton = ({
    children,
    onClick,
    className,
    type = 'button',
    ariaLabel,
    disabled = false,
  }: AnimatedButtonProps) => {
    return (
      <button
        type={type}
        aria-label={ariaLabel ?? children}
        disabled={disabled}
        onClick={onClick}
        className={cn(
          'relative h-12 w-32 overflow-hidden rounded-full bg-neutral-100 p-[2px] dark:bg-black',
          className
        )}
      >
        <div
          className="pointer-events-none absolute inset-0 z-0 h-full w-full scale-[1.4] animate-spin rounded-full [background-image:conic-gradient(at_center,transparent,#00b4d8_20%,transparent_30%)] [animation-duration:2s]"
          aria-hidden="true"
        />
        <div
          className="pointer-events-none absolute inset-0 z-10 h-full w-full scale-[1.4] animate-spin rounded-full [background-image:conic-gradient(at_center,transparent,#0077b6_20%,transparent_30%)] [animation-delay:1s] [animation-duration:2s]"
          aria-hidden="true"
        />
        <div className="relative z-20 flex h-full w-full items-center justify-center rounded-full bg-white px-6 py-2 text-black dark:bg-black dark:text-white">
          {children}
        </div>
      </button>
    );
  };
  
  export default AnimatedButton;
`}
/>

## Features

- **Animated:** Multiple spinning gradients for an eye-catching effect.
- **Accessible:** `aria-label` and `disabled` supported for improved accessibility.
- **Customizable:** Easily apply Tailwind utility classes with `className`.
- **Type-safe:** Strongly typed props for React & TypeScript.
- **Modern look:** Distinctive appearance for call-to-action buttons in light or dark mode.

---

## Customization

- Adjust colors or gradient stops in the button implementation for different accent colors.
- Change default size or border styles by editing Tailwind classes in the root `button`.
- Update the spinning gradient by editing the background-image and animation utility strings.

---

## Troubleshooting

- If gradients or animation do not appear, ensure Tailwind supports `[background-image:...]` and `[animation-...]` utility syntax.
- Check you are passing an `onClick` function and a string child to the button.
