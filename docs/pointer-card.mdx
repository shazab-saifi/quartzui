# Pointer Card

import { CodeBlock } from './CodeBlock';
import LiveCode from './LiveCode';

A card component that displays a pointer with a title when hovered.

## Usage

To use the pointer card component, import it from `@/components/PointerCard`.

<CodeBlock code={`import PointerCard from '@/components/PointerCard';`} />

## Props

The pointer card component takes the following props:

- `children`: The content to display inside the card.
- `className`: Additional classes to apply to the card.
- `title`: The title to display in the pointer.
