## Usage

To use the bento grid component, import it from `@/components/BentoGrid`.

<CodeBlock code={`import BentoGrid from '@/components/BentoGrid';`} />

## Props

The bento grid component does not take any props. It uses a default `gridItems` array to render the grid.
