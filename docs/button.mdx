# Button

A simple, accessible button component for all your UI actions.

## Live Preview

<div className="not-prose w-full overflow-x-auto">
  <LiveCode code={`<Button>Click me</Button>`} />
</div>

## Usage

To use the button component, import it from `@/components/Button`.

<CodeBlock code={`import { Button } from '@/components/Button';`} />

## Variants

The button comes in four variants: `primary`, `secondary`, `gradient`, and `destructive`.

### Primary

The primary button is the default button.

  <LiveCode code={`<Button variant="primary">Primary Button</Button>`} />
</div>

<CodeBlock code={`<Button variant="primary">Primary Button</Button>`} />
