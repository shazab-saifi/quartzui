# Floating Dock

import { CodeBlock } from './CodeBlock';
import LiveCode from './LiveCode';

A floating dock component that appears at the bottom of the screen.

## Usage

To use the floating dock component, import it from `@/components/FloatingDock`.

<CodeBlock code={`import FloatingDock from '@/components/FloatingDock';`} />

## Props

The floating dock component does not take any props. It uses a default `links` array to render the dock items.
