## Features

- **Animated SVG lines:** Beautiful color-animated lines synchronize between light and dark mode.
- **Animated grid background:** Subtle motion-inspired grid adapts to theme.
- **Logo clusters:** Displays top and bottom logos for brand context.
- **Responsive and accessible:** Layout adapts to card size and color scheme.

<hr style={{ borderColor: "var(--color-neutral-900)", borderWidth: 1 }} />

## Customization

This component is not currently configurable via props.  
To customize logos, title, or description, edit the implementation directly in `components/LinesCard.tsx`:

- Change the `topLogos` and `bottomLogo` arrays for different images.
- Edit the `title` and `description` inside the component function.
- Update linear gradients or grid styling for advanced visuals.

<hr style={{ borderColor: "var(--color-neutral-900)", borderWidth: 1 }} />

## Troubleshooting

- Ensure you are using [motion.dev](https://motion.dev/) for animation support.
- If SVG gradients do not animate, check `motion` and browser support.
- If images do not load, verify the URLs and Next.js external domains configuration.
- For theme switching, ensure the dark mode class is applied to `<html>` correctly.
