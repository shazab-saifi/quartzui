# Badge

import { CodeBlock } from './CodeBlock';
import LiveCode from './LiveCode';

A component to display a badge with a label and a colored dot.

## Live Preview

<div className="not-prose w-full overflow-x-auto">
  <LiveCode code={`<Badge label="Badge" />`} />
</div>

## Usage

To use the badge component, import it from `@/components/Badge`.

<CodeBlock code={`import Badge from '@/components/Badge';`} />

## Variants

The badge comes in six variants: `green`, `cyan`, `red`, `blue`, `yellow`, and `purple`.

## Props

The badge component takes the following props:

- `label`: The text to display on the badge.
- `variant`: The color of the badge.
- `className`: Additional classes to apply to the badge.
