# Text Shimmer

A modern React component that applies an animated shimmer effect to text, perfect for loading states, attention-grabbing headlines, or subtle visual flair.

## Installation

You can install the TextShimmer component with the following CLI command, or copy the implementation manually:

<InstallToggle
  cliCode="npx shadcn@latest add http://localhost:3000/r/text-shimmer.json"
  manualCode={`
  'use client';
  
  import { cn } from '@/lib/utils';
  import { motion } from 'motion/react';
  import { useMemo } from 'react';
  
  interface TextShimmerProps {
    duration?: number;
    children: string;
    className?: string;
    spread?: number;
    baseColor?: string;
    shimmerColor?: string;
  }
  
  const TextShimmer = ({
    duration = 3,
    children,
    className,
    spread = 2,
    baseColor = '#FFF',
    shimmerColor = '#000',
  }: TextShimmerProps) => {
    const dynamicSpread = useMemo(() => {
      return children.length * spread;
    }, [children, spread]);
  
    return (
      <motion.p
        initial={{ backgroundPosition: '100% center' }}
        animate={{ backgroundPosition: '0% center' }}
        transition={{
          repeat: Infinity,
          duration,
          ease: 'linear',
        }}
        style={
          {
            '--spread': \`\${dynamicSpread}px\`,
            '--base-color': baseColor,
            '--base-gradient-color': shimmerColor,
            backgroundImage: \`var(--bg), linear-gradient(var(--base-color), var(--base-color))\`,
          } as React.CSSProperties
        }
        className={cn(
          'relative inline-block bg-[length:250%_100%,auto] bg-clip-text',
          'text-transparent',
          '[background-repeat:no-repeat,padding-box] [--bg:linear-gradient(90deg,#0000_calc(50%-var(--spread)),var(--base-gradient-color),#0000_calc(50%+var(--spread)))]',
          className
        )}
      >
        {children}
      </motion.p>
    );
  };
  
  export default TextShimmer;
`}
/>

## Features

- **Animated shimmer:** Moving highlight animates smoothly across text.
- **Highly customizable:** Control duration, spread, base color, shimmer color, and text style.
- **Type-safe:** Fully typed props for optimal DX.
- **Universal:** Works with any string content.

<hr style={{ borderColor: "var(--color-neutral-900)", borderWidth: 1 }} />

## Customization

- Adjust the `duration` and `spread` props to control speed and width of shimmer.
- Use `baseColor` and `shimmerColor` for visual style.
- Tailwind classes via `className` for size, font, and color.
- Modify animation or styles inside the component for advanced use cases.

<hr style={{ borderColor: "var(--color-neutral-900)", borderWidth: 1 }} />

## Troubleshooting

- Ensure you pass a string as children; other nodes won't render as intended.
- If the shimmer doesn't animate, check that your project is using [motion.dev](https://motion.dev/).
- If custom text styles don't apply, verify your Tailwind CSS config includes the used utilities.
